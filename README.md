# Simulação de Ransomware com Python

## Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio prático da plataforma [Digital Innovation One (DIO)](https://www.dio.me/), com o objetivo de compreender o funcionamento de um ataque de ransomware por meio da implementação de um script em Python.

A atividade consiste no desenvolvimento de dois scripts: um responsável pela criptografia de arquivos e outro pela descriptografia, permitindo compreender na prática como esse tipo de ameaça pode comprometer a disponibilidade e o acesso a informações.

O projeto possui finalidade exclusivamente educacional e deve ser executado em um ambiente controlado, utilizando arquivos de teste.

## Objetivos

* Compreender o funcionamento de ataques de ransomware.
* Aplicar conceitos de criptografia utilizando Python.
* Explorar bibliotecas relacionadas à manipulação e proteção de arquivos.
* Implementar processos de criptografia e descriptografia.
* Entender os impactos de ataques que comprometem a disponibilidade dos dados.
* Desenvolver conhecimentos práticos em segurança da informação.


### Arquivos principais

* **encrypter.py:** script responsável por realizar a criptografia dos arquivos de teste.
* **decrypter.py:** script responsável por descriptografar arquivos previamente criptografados.

## Desenvolvimento do Laboratório

A atividade foi dividida nas seguintes etapas:

1. **Preparação do ambiente:** configuração do ambiente Python para execução dos scripts.
2. **Implementação da criptografia:** desenvolvimento do script responsável por criptografar arquivos utilizando uma biblioteca específica.
3. **Implementação da descriptografia:** desenvolvimento de um segundo script para recuperar os arquivos criptografados.
4. **Testes controlados:** execução dos scripts utilizando arquivos fictícios em um diretório isolado.
5. **Análise dos resultados:** verificação do funcionamento dos processos de criptografia e descriptografia.

## Considerações de Segurança

Este projeto possui finalidade exclusivamente educacional e foi desenvolvido para demonstrar conceitos de criptografia e segurança da informação.

O ransomware é uma ameaça cibernética que pode impedir o acesso a arquivos e sistemas, causando prejuízos significativos a organizações e usuários.

A implementação deve ser utilizada exclusivamente em ambientes controlados, com arquivos de teste e sem acesso a dados de terceiros.
